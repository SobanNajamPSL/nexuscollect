# Narration — recording sheets

Generated by `npx tsx scripts/record-demo.ts --dry --manifest`. Do not edit by hand:
these lines are the captions the film puts on screen, so the script and the picture
cannot disagree. Change the wording in `scripts/record-demo.ts` and regenerate.

## How to record

One file per beat is easiest — read the numbered lines in order, leaving a clear
**one to two second pause** between them. The pauses are how the pipeline finds
where each line ends, so they matter more than they look like they should.

```
docs/demo/narration/audio/<beat-id>.wav        one take for the whole beat
docs/demo/narration/audio/<beat-id>/01.wav    or one file per line, if you prefer
```

WAV or AIFF, mono is fine, 44.1 kHz or better. Then:

```bash
npx tsx scripts/measure-narration.ts
```

which splits any whole-beat takes, checks it found the right number of lines, and
writes `durations.json`. After that, re-record the film and the beats as usual and
every caption is held to the length of its narration instead of an estimate.
